# Контекст проекта SmartHome

Актуализировано: 23 сентября 2026 года. Перед следующей задачей прочитайте этот файл и правила в `AGENTS.md`. После работы обновите состояние и журнал ниже.

## Задача и источники

АСУ «Умный дом»: приложение C# Windows Forms для .NET Framework 4.8. По замыслу система управляет устройствами через контроллеры ESP32, отслеживает датчики, выполняет сценарии, учитывает права пользователей и хранит устройства в БД.

Источник назначения классов — `Docs/Описание_файлов_SmartHome.docx`. Документ описывает 28 типов в `Models/`, `Services/` и `Data/`, включая перечисления. Ссылки на пункты ТЗ в нём есть, но отдельное полное ТЗ в рамках этой задачи не изучалось. Назначение класса не означает, что его методы уже реализованы.

## Что уже реализовано в коде

- Создан каркас моделей, сервисов и хранилища; общие свойства вынесены в Device и Sensor.
- `Form1.SetupDemo` создаёт комнату «Гостиная», два контроллера, лампу, датчик воды и сервопривод крана. Есть интерфейс яркости, состояния, режима и журнала.
- Яркость применяется при отпускании мыши над ползунком. `Light.SetBrightness` проверяет диапазон 0–100; нулевая яркость выключает лампу. Ошибки отображаются в форме.
- Флажок связи меняет `ControllerNode.IsOnline`. При отказе команды лампа получает Offline, а в журнал добавляется сообщение.
- Кнопка протечки устанавливает показание 1. Проверка порога вызывает Alarm, режим Emergency, установку угла всех Servo в 0, запись событий и предупреждение.
- Кнопка сброса обнуляет показание датчика и возвращает Normal. Повторное открытие крана при сбросе не реализовано.
- Уведомления проходят через `NotificationService.Alert` и `SmartHomeSystem.AlertRaised`; журнал хранится в памяти.

Это результат чтения исходников, а не подтверждение запуском или испытанием оборудования.

## Что пока не реализовано и что учитывать

- `ControllerNode.SendCommand` только возвращает IsOnline: сетевой отправки и реального управления ESP32 нет.
- `DeviceRepository.Add/Update/Delete/Search`, `DiscoveryService.FindNodes`, `SmartHomeSystem.RunScenario`, `Scenario.Execute`, `ScenarioAction.Apply`, `Trigger.IsFired` и `User.CanControl` выбрасывают NotImplementedException.
- `CommandValidator.Validate` проверяет только наличие устройства, контроллера и непустой команды. Диапазон яркости проверяется в Light; конфликтов команд пока нет.
- Конкретные датчики, Heater и SmartSocket используют только поведение базовых классов. Sensor сравнивает Value с Threshold; чтения с оборудования нет.
- Word-документ устарел в описании пустой формы: демонстрационный интерфейс уже написан. Остальные планы из документа также нужно сверять с кодом.
- Автоматизированных тестов и порога покрытия нет. В этой сессии сборка, ручной запуск и работа оборудования не проверялись.
- Общий GitHub-репозиторий: https://github.com/EEEEgggoor/SmatHome_KPO. Основная ветка — `main`; проверенный HEAD: `56154297c3bd60b171c5130ea2aa52ea75c6f9c9`. На 23 сентября 2026 года дерево содержит только `LICENSE`, исходников приложения там нет.

Добавлен `.gitignore` для `.vs/`, `bin/`, `obj/`, пользовательских настроек, результатов тестов и временных файлов Office. Исходники и документация включаются в первый локальный коммит приложения.
