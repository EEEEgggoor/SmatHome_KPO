# Команды приложения и контроллера

Android-часть задания выполнена 20 октября 2026: чтение воды — `0x02`, питание и
яркость света — `0x03`, включение/выключение реле — `0x04`. Исходная команда `0x01`
сохранена. Добавление светового устройства больше не требует температуры света.

**Прошивка пока обрабатывает только `0x01`.** Автору ESP нужно добавить обработчики
новых команд с указанным форматом запросов и ответов, затем проверить оборудование.
Наличие Android-команд не означает, что соответствующие выходы ESP уже работают.

- [Формат пакетов, номера команд, подтверждения и примеры байтов](SmartHome_App/Docs/CONTROLLER_INTEGRATION.md#tcp-команды-android--20-октября-2026).
- [Esp32Wire](SmartHome_App/app/src/main/java/com/example/smarthome/integration/Esp32Wire.java) — формирование пакетов.
- [Esp32TcpClient](SmartHome_App/app/src/main/java/com/example/smarthome/integration/Esp32TcpClient.java) — TCP-отправка и проверка ответов.
- [Esp32NetworkClient](SmartHome_App/app/src/main/java/com/example/smarthome/integration/Esp32NetworkClient.java) — поиск адресов и вызов TCP-клиента.
- [Esp32ControllerGateway](SmartHome_App/app/src/main/java/com/example/smarthome/integration/Esp32ControllerGateway.java) — связь с DeviceControlService.

Участнику UI остаётся подключить кнопки управления к асинхронным методам сервиса и
убрать температуру света/воды из интерфейса. Команда клапана отдельно не определена.
