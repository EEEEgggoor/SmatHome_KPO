# Тесты прошивки ESP

Запускаются на компьютере без подключения ESP32 и без ESP-IDF. Нужны PowerShell и GCC. Тестируется настоящий код из `main/`; заглушки заменяют только внешние API NVS, GPIO, ADC, LEDC и FreeRTOS.

Из каталога `SmartHome_ESP`:

```powershell
.\test\run_tests.ps1
```

Если GCC не в PATH:

```powershell
.\test\run_tests.ps1 -Compiler 'C:\msys64\ucrt64\bin\gcc.exe'
```

Скрипт собирает и запускает семь тестовых программ с `-std=c11 -Wall -Wextra -Werror`. При ошибке компиляции или проверки выполнение прекращается. Временные исполняемые файлы удаляются; прошивка на плате не изменяется.

| Файл | Проверки |
|---|---|
| `test_usb_line_parser.c` | Частичные USB-пакеты, CRLF, пробелы, точные границы SSID/пароля, переполнение с защитными байтами, пустые строки, нулевая ёмкость, повторная инициализация |
| `test_storage.c` | Сохранение и загрузка, порог воды, совместимость со старой записью без порога |
| `test_storage_failures.c` | Неверные аргументы и строки, отсутствие записи, неправильный размер, ошибки открытия/чтения/записи/commit, освобождение NVS handle, сохранение состояния при сбросе online |
| `test_water_policy.c` | Калибровка, ограничение процентов, неизвестные показания, граница закрытия и запас уровня для открытия |
| `test_control_device.c` | Реле, ручной клапан, сохранение и применение порога, подтверждённый снимок устройства |
| `test_command_validation.c` | Длины всех команд, неизвестная команда, ID с нулевым дополнением, соответствие типу, диапазоны света/порога, ошибки оборудования и отправки, закрытие при ошибке ADC, отсутствие сетевой отправки под mutex |
| `test_device_io.c` | Запуск света/реле/воды в выключенном или закрытом состоянии, PWM света, полярность реле, 13-битный ADC ESP32-S2, закрытие при высоком уровне/ошибке ADC, отсутствие самопроизвольного открытия после снижения уровня |

Новые USB/командные/NVS-наборы содержат 21 отдельно названный сценарий; остальные наборы дополнительно проверяют ранее реализованное поведение.

## Что требует платы

Эти тесты не проверяют USB enumeration в Windows, реальную работу TCP/Wi-Fi, планировщик FreeRTOS, электрическое подключение, калибровку датчика и ход сервопривода. Тест ADC повторяет ограничения драйвера ESP32-S2 и ловит ошибку 12-битной настройки, но появление COM-порта нужно проверить после прошивки на устройстве.

Тест NVS использует замену API и проверяет обработку результатов; сохранность реальной flash при отключении питания им не моделируется.
